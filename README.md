# 漫画私藏 · ur-manga-web

选择最喜欢的长篇、中篇、短篇和同人漫画，生成个人推荐卡。每类最多一部，可留空；篇幅由用户自行归类。

源代码仓库：https://github.com/itoyohane/ur-manga-web

## 本地运行

无需安装依赖或构建。克隆仓库后运行：

```bash
git clone https://github.com/itoyohane/ur-manga-web.git
cd ur-manga-web
python -m http.server 8000 --directory dist
```

打开 `http://localhost:8000`。使用 HTTP 访问，避免直接打开 HTML 导致模块加载受限。静态托管目录为 `dist/`。

## 使用

1. 点击长篇、中篇、短篇或同人选择格。
2. 搜索作品，或手动输入书名、作者 / 社团并上传封面。
3. 可填写推荐理由，在“署名与介绍”中编辑卡片文字。
4. 展开预览，下载 1200 × 1500 PNG。

手机上使用双列选择卡片、底部下载按钮和底部选择面板。输入框使用 16px 字号，避免 iOS 聚焦放大；适配安全区，预览与署名默认折叠。

## 界面样式

页面与导出的推荐卡遵循 [DESIGN.md](./DESIGN.md) 中的 Mobbin Minimal 设计：黑白配色、大字号标题、轻边框卡片、胶囊按钮与浅灰输入框。样式变量集中在 `dist/style.css` 的 `:root`，Canvas 推荐卡配色在 `dist/app.mjs` 的 `palette`。

仓库未包含 M Saans 字体文件，优先使用本机已安装的同名字体，否则回退到系统无衬线字体；无需远程字体请求。桌面端采用左右编辑与预览布局，手机端保留双列卡片、折叠预览及底部下载栏。

## 模糊与组合搜索

统一搜索 Bangumi 与 AniList，无需选择数据源或配置 API 密钥。

| 输入 | 处理方式 |
| --- | --- |
| `百合 雪子` / `雪子 百合` | 识别百合题材，核对作者身份，通过作者关联作品查找漫画，再筛选题材 |
| `GL 雪子` / `雪子画的百合漫画` | 支持题材同义词及有限的作者表达式 |
| `百合 日常` | 同时匹配两种题材 |
| `双人间` / `One Piece` | 匹配书名片段、别名、大小写和部分简繁变体 |

输入停顿 700ms 后自动查询，支持中文输入法；新查询会取消旧请求。结果显示匹配的作者、题材和数据来源，并对重复条目合并。请求结果缓存 5 分钟，限制并发和单次关联作品展开数量。

搜索基于目录元数据与规则解析，**不生成不存在的作品**。这不是通用自然语言理解：当前识别百合、日常、恋爱、校园、悬疑、奇幻、科幻、运动、搞笑、冒险与恐怖等题材；错字匹配仅用于已召回候选，不能保证纠正任意输入。两字作者名不做近似替换；中文 / 罗马字作者名通过目录中的别名核对。

作者作品较多时最多展开前 24 部，AniList 作者作品最多读取前 40 部；最终最多展示 24 条。资料缺失、标签遗漏、分页和源站限流都可能影响召回。书籍分类可能包含未标明类型的非漫画；已知小说和画集会排除。成人条目不纳入在线搜索，同人作品可手动添加。

## 数据与隐私

搜索关键词发送给 Bangumi / AniList。上传封面在浏览器中缩放，支持 JPG、PNG、WebP，最大 8 MB；封面和选择仅保存于当前浏览器，不上传服务器。在线封面由浏览器从图片源加载。清除网站数据会删除本地收藏卡。

搜索选中的封面保留原始地址，供编辑区与选择卡片显示；能成功读取的图片会另存为本地副本，用于 Canvas 预览与 PNG 导出。图片源未开放跨域读取时，页面仍尝试显示在线封面，并提示导出将使用文字封面。可在已选漫画的编辑区直接上传或替换封面，无需重新输入作品信息。原始图片也无法加载时显示失败提示。

旧版本已保存的条目如果没有封面地址，需要重新搜索选择一次，或直接上传封面。

## Sites 部署

`.openai/hosting.json` 记录现有 Sites 项目与静态目录 `dist/`。使用 Sites 发布时复用该项目，先同步源代码，再打包并发布；GitHub 用于项目版本管理。新站点默认仅所有者可访问，公开分享需要调整站点访问设置。

部署环境必须允许连接 Sites 源码仓库。同步失败时，站点尚未上线；预设域名不代表部署成功。发布凭证仅通过 Sites 工具和进程标准输入传递，不写入源码或配置文件。

## 目录与检查

- `dist/`：可直接托管的 HTML、CSS、原生 JavaScript 与 Canvas 图片生成。
- `dist/search.mjs`：查询解析、作者作品检索、筛选、排序、缓存与容错。
- `tests/`：保存恢复、API 转换、组合搜索与异常处理测试，使用模拟响应，不依赖网络。
- `.github/workflows/check.yml`：推送及 PR 自动运行语法检查和测试。

```bash
node --test tests/*.test.mjs
node --check dist/app.mjs
node --check dist/model.mjs
node --check dist/search.mjs
node --check dist/cover.mjs
```

推荐 Node.js 22。JavaScript 使用两个空格缩进。测试不能替代移动浏览器实测；正式发布前应检查搜索、上传、恢复、PNG 下载及 iOS / Android 键盘布局。需要凭证的新服务应通过后端代理访问，不应把密钥写入前端。

API 文档：[Bangumi OpenAPI](https://github.com/bangumi/server/blob/master/openapi/v0.yaml)、[AniList](https://docs.anilist.co/)。
